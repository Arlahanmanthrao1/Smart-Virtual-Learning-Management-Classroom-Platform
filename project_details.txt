5. CURRENT LOGIN AND LOCAL RUN INSTRUCTIONS
-----------------------------------------------------------------------------
Do not store passwords, private keys or a real Neon connection string here.
Use actual accounts created by the administrator, not the old sample logins.

First administrator (only if the deployed database has no administrator):
From backend/, run:
  .\.venv\Scripts\python.exe scripts/create_first_admin.py --email YOUR_COLLEGE_EMAIL --clipboard
Replace YOUR_COLLEGE_EMAIL with the intended real administrator email. Follow
the hidden-input prompts; copy the complete Neon connection string from the
correct database. The bootstrap password requires at least 12 characters and
at most 72 UTF-8 bytes. The script refuses to overwrite an existing account.
This is an instruction, not a claim that an administrator was created today.

Local backend (PowerShell, start from the repository root):
  cd backend
  python -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -r requirements.txt
Create backend/.env from backend/.env.example ONLY if .env does not already
exist. Edit its real settings privately; do not overwrite existing credentials.
Then run:
  .\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000
Local API documentation: http://localhost:8000/docs
Documentation is disabled on Vercel. Account creation still requires admin
authentication even when using the local API documentation.

Local frontend (a second terminal, start from the repository root):
  cd frontend
  npm ci
Create frontend/.env from frontend/.env.example ONLY if it is missing.
Use VITE_API_BASE_URL=http://localhost:8000 for the local backend. Then run:
  npm run dev
Open the local URL printed by Vite (normally http://localhost:5173).

Virtual-environment activation is optional when using the explicit python.exe
commands above. If needed from the repository root, the correct command is:
  .\backend\.venv\Scripts\Activate.ps1
Note the separator between backend and .venv. Git does not require activation.

Further repository setup guides: backend/JAAS_SETUP.md, backend/README.md and
VERCEL_DEPLOYMENT.md. For delivery status, use the dated update in this file;
older setup notes may describe steps before the latest push/deployment.
